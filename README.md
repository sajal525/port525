# Portfolio — Sajal Jaiswal

A personal portfolio website for me, an engineering student interested in web development and Artificial Intelligence and Machine Learning. The site introduces me, presents selected web projects, and provides ways to connect.

**Live website:** [sajal525.github.io/port525](https://sajal525.github.io/port525/)

## Sections

- **Home** — introduction and résumé link
- **Projects** — previews of two web design projects
- **About** — education, skills, goals, and interests
- **Contact** — contact form layout and social links

## Featured projects

- [Hotel booking homepage](https://sajal525.github.io/website0/web1.html) — a responsive hotel booking page inspired by Trivago.
- [Google homepage clone](https://sajal525.github.io/website-1/index.html) — a Google-style search homepage made with HTML and CSS.

## Built with

- HTML5
- CSS3
- Bootstrap 4.4.1, loaded from jsDelivr
- jQuery Slim 3.4.1 and Popper.js 1.16.0 for Bootstrap components
- A small inline JavaScript image fallback
- Google Fonts

## Project files

```text
port525/
├── index.html       # Portfolio page content
├── style.css        # Custom styles and responsive layout
└── Assets/          # Images used by the page
```

## View locally

1. Download or clone this repository.
2. Open `index.html` in a browser.

The page loads Bootstrap and fonts from external CDNs, so an internet connection is needed for those resources.

## Contact and deployment notes

The contact form currently points to `forms/contact.php`, but that handler is not included in this repository. GitHub Pages serves static files and does not run PHP, so connect the form to a form service or another backend before relying on it to deliver messages.

The résumé link and the “View Source Code” project links should also be checked: the résumé file is not included in this folder, and the source-code links in the page are currently placeholders.
